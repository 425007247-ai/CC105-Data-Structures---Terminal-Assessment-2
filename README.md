# University Student Service & Queue System

## Project Overview
A menu-driven C++ application developed for CC105 – Data Structures with Laboratory at National Teachers College. The system manages university student records and service requests using dynamic data structures.

## Features
- Student record management (Add, Display, Search, Update, Delete)
- Doubly Linked List for student records
- Linked Stack for audit trail and undo operations
- Circular Queue for regular service requests
- Linked Priority Queue for priority service requests
- Linear Search and Binary Search
- Bubble Sort, Selection Sort, and Insertion Sort
- Benchmarking of sorting algorithms
- Dynamic memory management using pointers, new, and delete

## Technologies Used
- C++ (C++11 or later)
- Code::Blocks or any compatible C++ compiler
- GitHub for version control

## How to Run
1. Download or clone this repository.
2. Open Student_Service_Queue_System.cpp in Code::Blocks.
3. Build and run the program using a C++11-or-later compiler.
4. Select an option from the main menu.
